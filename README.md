# 语文教师·班主任一体化工作台

人教版六年级（五四制）初中语文教师 + 班主任一体化工作台，蓝白简约风格，iOS 风格线性图标。

## 功能板块

- **首次设置**：年级、上/下学期、教学周数、开学日期（所有“第几周”按开学日自动计算）
- **语文教学工作区**：教学仪表盘、课后反思（Word 导出）、作业管理（分层题库、Excel 导入导出、默写错题归集）、成绩分析（多维图表、Word 学情报告、Excel 导出）、学科待办备忘
- **班主任工作区**：学生名单管理、班级管理（数据与教学区互通）
- **课表管理区**：课表总览、个人授课课表（图片/Excel 导出）、班级全局课表、调课补课登记（台账导出）

## 使用方式

直接用浏览器打开 `index.html` 即可使用（图表/Excel 导出依赖 CDN，需联网）。

数据保存在浏览器 localStorage 中，请在同一浏览器中持续使用。
