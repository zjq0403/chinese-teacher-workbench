# 语文教师工作台

人教版六年级（五四制）初中语文教师一体化工作台，蓝白简约风格，iOS 风格线性图标。

## 功能板块

- **语文教学工作区**：教学仪表盘、课后反思（Word 导出）、作业管理（ABCDF 五级评级、积分排名、分层题库、Excel 导入导出、AI 智能匹配评级）、成绩分析（多维图表、Word 学情报告、Excel 导出）、学科待办备忘
- **学生名单 + 成绩分布**（含补差/培优标签）
- **课表管理区**：课表总览、个人授课课表（图片/Excel 导出）、班级全局课表、调课补课登记（台账导出）
- **数据备份 / 恢复**：JSON 文件下载与剪贴板复制/粘贴（静态托管无后端，多设备通过备份文件互相同步）

## 跨设备同步

工作台是纯静态应用，所有数据存放在本机 `localStorage`。由于 GitHub Pages 无后端，多设备同步采用 **JSON 备份 → 跨端导入** 方案：

1. A 设备：底部侧栏 → **数据备份 / 恢复** → 下载 JSON（或复制到剪贴板）
2. 通过云盘/微信/邮件把 JSON 发到 B 设备
3. B 设备：同一入口 → **从文件** / **粘贴文本** → 恢复

## PWA 离线 + 主屏安装

- 支持添加到手机主屏幕（全屏独立窗口运行）
- 完整的离线缓存：核心资源 + 7 个 CDN 库全部缓存，离线打开仍可使用
- iOS Safari：分享 → 添加到主屏幕；安装后从主屏启动即全屏
- Android Chrome：菜单 → 安装应用 / 添加到主屏幕

## 使用方式

- **手机 / 平板**：在线访问 [https://zjq0403.github.io/chinese-teacher-workbench/](https://zjq0403.github.io/chinese-teacher-workbench/)，添加到主屏幕后离线可用
- **电脑**：直接打开 `index.html`（或访问上面的链接）
- **离线桌面**：下载后双击 `index.html` 即可（图表/Excel 导出依赖 CDN，首次使用需联网加载）

数据保存在浏览器 localStorage 中，建议在录入重要数据后通过「数据备份 / 恢复」导出一份 JSON 备份。
